# Data Analyst Bootcamp

A self-directed path from descriptive epidemiology to data analysis,
built for the AI era: SQL, Python, BI, statistics, causal inference
and AI-assisted analysis, all on open health data.

Ground rules: public data only, no workplace data, free tools only,
and every number in a project is traced to code or to a source.

## How I work with AI

- **The model drafts, I verify.** Numbers come from code I run or from a source I opened, never from a chat answer alone.
- **Decisions are mine.** Definitions (numerator, denominator, population, unit, period) are written into the request, not left to the model.
- **Describe before analysing.** For an unfamiliar file, the first request only describes it and reports problems; cleaning starts after I review that.
- **Prompts are practice too.** Each prompt drill is graded on method separately from content, against a rubric set in advance.
